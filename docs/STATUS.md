## Verification

- 26 JVM importer tests pass.
- Shared Java sources compile against Android API 34's framework surface with Java 8 syntax.
- Debug APK assembles with JDK 17, Android platform/build tools 34 and the pinned SDK source.
- Original integration patches applied to clean, pinned upstream source checkouts.
- No live Mumble audio, watch emulator, physical watch or paired phone was tested.
- No TAKS service was deployed or restarted, and no server package generator was modified.

The inspected TAKS snapshot has an existing unrelated regression: one topology test expects
`GruppL-QQEA`, while the current implementation returns `GruppL-EAQQ`. The other three tests
in that suite pass. The plugin does not change that topology or weaken its test.

## Next milestones

1. Implement and test Mumble/Opus receive audio, channel joining and native press/hold/release PTT.
2. Integrate negotiated WearTAK microphone streaming and an independent capture path.
3. Implement paired audio routing, including a binary phone relay where no OS Internet route exists.
4. Add TAKS-side per-device authentication/trust provisioning in the TAKS repository.
5. Build the complete upstream integrations and test against Vx plus real watch/phone hardware.
6. Validate background behaviour, headset/PTT devices, handoff, battery use and recovery.
