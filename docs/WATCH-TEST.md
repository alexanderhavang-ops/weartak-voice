# WearTAK Voice 0.6.20 · watch test card

Start with your Galaxy Watch Ultra on your wrist, ATAK 5.8 CIV with Companion on the phone, and VX on a second endpoint in the same Mumble room. Test on the watch speaker first. Run the **plugin** from WearTAK. Disconnect standalone Voice so only one app owns the microphone and bud controls. Note the host, Voice and Companion versions and whether each is DEV or release.

| ✓ | Do this | Pass when |
|---|---|---|
| ☐ | Connect the watch to Companion. Open Watch Details, disconnect the phone link and reconnect. Leave Refresh alone. | The watch and Voice receiver show up automatically. Sending becomes available after the plugin is loaded. |
| ☐ | In Companion choose a **known, uniquely named** VX ZIP. Send over Bluetooth. On the watch review the endpoint and room, then accept. | Companion shows staged and then applied. Voice shows the intended room. VX sees the watch join under the expected name. Receiving or saving the ZIP alone does not verify login. |
| ☐ | Test a fresh, password-protected generic Mumble endpoint. Enter its shared password once, leaving account username blank. Separately test the TAKS setup sound if you use it. | The generic watch name appears on the server. A fresh TAKS ticket provisions its account and joins without typing a password. Record which path you used. The current channel ZIP importer supplies channel data. It does not import a Mumble login. |
| ☐ | On the speaker, send “one” from VX. Hold on-screen **PTT**, wait for the opening sound, say “two”, release. Enable Back tap-to-toggle and repeat in the Voice foreground. | Both parties hear the words. VX sees transmission stop on release or second Back press. Voice stays open. |
| ☐ | Connect Buds3 Pro to the **watch**. Select tap-to-toggle. Do five single-squeeze start/stop pairs. If a pair fails, try **Repair** once, then one on-screen PTT, recording which restores control. | Each squeeze changes TX exactly once. You hear the opening cue, quiet reminders about every 3 seconds and the closing cue. Once idle, the buds are quiet and music stays paused. |
| ☐ | Toggle TX on and remain silent. Then start again and speak/read continuously past one minute. | Silence closes TX after about 5 seconds. Continuous speech closes it by 60 seconds. Listen for the closing cue and confirm on VX that the mic released both times. |
| ☐ | Press Home, let the display go dark and keep it dark. Have VX send numbered calls at 15, 30, 60 and 180 seconds. Wake the watch and tap the channel for diagnostics/socket history. | You hear every call, VX sees the watch stay joined, and the same socket spans the run. Record missed call numbers, drop/reconnect times and Wi-Fi or LTE. Read history after waking. Live ADB is optional. |
| ☐ | Clear **cache only** for the Voice plugin in watch Settings → Apps → Voice → Storage (menu names vary). Reopen and reconnect. Then reboot the watch and reconnect once more. | Saved channel, login and Back assignment survive. Companion rediscovers capabilities. Two-way audio and bud start/stop work again. |
| ☐ | Last, on a test configuration, clear **Voice plugin storage/data**. This erases its login, channels, mappings and history. Send a **new test ZIP with a changed room or label** so the host’s earlier receipt cannot suppress the resend. | Voice starts clean. Companion re-onboards it without manual Refresh. Apply, join, then confirm two-way speech again. |

**Quick recovery check.** Repeat the package transfer over Wi-Fi. Use the wrong pairing code once and confirm the current channel still works. Pair with the displayed code, send a different room and verify it on VX. For a standalone comparison, disconnect the plugin and repeat the speaker test in standalone Voice.

**Release acceptance · after Alex has enabled the verified Voice signer.** Use a test watch or back up its settings. Install signed release core → signed release plugin and run the Bluetooth handoff and two-way PTT. Uninstall those two test apps, reverse the install order and repeat. With a DEV or unapproved test plugin, release core must withhold voice handoff. Check an existing non-Voice plugin still loads. A DEV pass or clearing cache cannot establish release compatibility.

**If something fails**, record the step, builds, network, actual room or peer, screen and wrist state, what each side heard, and the socket-history reason. Save diagnostics before clearing data. No full-watch reset, ATAK storage wipe or buds factory reset is needed for this card.
